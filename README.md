# userkit

AIチャット「zeta」のための非公式ツール集です。
すべてブラウザだけで動き、入力した文字や画像はその端末の中だけで処理・保存されます（サーバーへの送信・アカウント登録はありません）。

**サイト**: https://purity0km-droid.github.io/userkit/

| ツール | できること |
|---|---|
| userprof | userのプロフィール・年表・設定メモ・画像を、プロットごとにまとめて保存。zetaのユーザープロフィール(1000字)を丸ごと保存して、字数を数えながら1000字に収める道具も |
| userhome | userの住まいの設定文から、ドアや窓の入った階ごとの間取り図を起こして画像（PNG）で保存。zetaに貼る住まいの覚え書き（マークダウンかふつうの文）づくりと、talklogのログとの照らし合わせも |
| userpair | 2人（または1人）のキャラシートを作って画像で保存 |
| userline | プロフィール・年表・まとめ・関係を1枚にしたタイムライン風ペアカードを画像で保存 |
| usermix | 2人のための曲を並べたプレイリストを、音楽アプリ風のプレイリストの画面（縦長）か再生画面（横長）にして画像で保存。曲ごとに選んだ人の印と、選んだわけ・好きな一節を添えられる。曲ごとのジャケット（正方形）も作れ、レコードが回る短い動画（MP4・GIF）でも保存できる |
| usersns | セットログ風のVlog画面(2〜4人)・インスタ風の投稿(タグ付け)・ストーリー・LINE風のトーク・Twitter風のプロフィールとリプ画面を、1つの画面で切り替えて作って画像で保存 |
| usercard | userのプロフィールを、ホロ箔や単色の箔押しのトレカ風カードにして、画像（PNG）と短い動画（MP4）で保存 |
| userid | userの社員証・学生証・自己紹介カードなどを、載せる項目を自由に選んで作り、表・裏・両面を画像（PNG）で保存 |
| usersnap | userの写真をチェキ風のフチと落書きで仕上げ、そのままの1枚と落書きした1枚をL判に並べて、JPEG・PNG・レイヤーに分けたPSDで保存。2L判には1枚ずつ実寸のまま3枚並べられる |
| usermovie | 写真に映画の字幕と黒帯を重ねて、画像（PNG）で保存。字幕はtalklogのログから選べ、英語の字幕と縦書きの字幕も付けられる。カットを縦に並べた1枚で、会話の流れも見せられる |
| usermask | スクショのユーザー名・アイコンを、なぞるだけで隠す。登録した名前・アイコンは次の画像から自動で見つける |
| talklog | zeta（Web版）のトークを、吹き出しのまま読めるHTMLファイルに保存。書き出したログの閲覧・テキスト化も |
| charplot | zetaのプロットを編集画面と同じタブの並びに貼って、ブラウザに保存。紹介ページは記法を選んでマークダウンで書き、zetaに近い見え方で確かめてからコピーできる。イントロのプレビュー、前の版との見比べ、復元用ファイルの書き出しも |

各ツールへは、サイトのトップから開けます。更新履歴は、サイトの「更新履歴」のページにまとめています。

## 注意

- zeta公式とは関係のない、ファンメイドのツールです。
- データはブラウザに保存されます。閲覧履歴やサイトデータを消すと失われるため、各ツールの「保存」「バックアップ」でファイルに書き出してください。
- talklog は zeta の画面の作りに合わせて動いています。zeta 側の変更で動かなくなることがあります。

## 開発

ビルドは不要です（素の HTML / CSS / JavaScript）。ローカルで確認するときは、このフォルダで簡単なサーバーを立てて開きます。

```
python -m http.server 5175
```

→ http://127.0.0.1:5175/

- `assets/` … 共通の部品（kit.js / kit.css：ツールの一覧・共通バー・ダイアログなど、changelog.js：更新履歴、editor.js / editor.css：userpair・userline・usermix・usersns の編集部品）
- `dev/zeta-mock.html` … talklog の収集スクリプトを確かめるための模擬トーク画面（zeta の画面ではありません）

PNG書き出し（userpair / userline / usermix / usersns / usercard）には [html-to-image](https://github.com/bubkoo/html-to-image)（MIT）を CDN から読み込んで使っています。
PSD書き出し（usersnap）には [ag-psd](https://github.com/Agamnentzar/ag-psd)（MIT）を CDN から読み込んで使っています。
ジャケット（usermix）と字幕（usermovie）の書体は Google Fonts から読み込んで使っています。字幕の英語の書体（Arimo・Inter・Atkinson Hyperlegible Next・Jost・EB Garamond・Courier Prime）と BIZ UDPゴシックは、どれも SIL Open Font License 1.1 です。しねきゃぷしょんは作者の配布条件に沿って、assets/fonts/cinecaption/ に説明書きと一緒に同梱しています。作者は chiphead 氏で、ひらがなのデザインは雑念の塊氏です。ほかのフォントのファイルはこのリポジトリに含めていません。
