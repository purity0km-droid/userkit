zetaのトークを、
吹き出しのまま手元に保存

zeta(Web版)のトーク画面で動かすと、読み込まれた発言を集めて、1つのHTMLファイルに書き出します。ファイルはブラウザで開くだけで読めます。無料・登録不要。

読み取った内容はあなたの端末の中だけで扱い、どこにも送信しません。

黒羽 蓮読みかけの本に栞を挟んで、顔を上げる。
……遅い。待ちくたびれた。
放課後の図書室に、雨の音だけが響いている。
あなたごめん、委員会が長引いて。

1. 準備(はじめの1回だけ)

Chrome・Edge・Safari・Firefox など。ブックマークバーを表示しておいてください。

  1. 下の 「talklogで保存」 ボタンを、ブックマークバーへドラッグして置きます。
    talklogで保存← ドラッグ
  2. ドラッグできないときは、し、ブックマークを新しく作って「URL」欄に貼り付けます(名前は「talklogで保存」など)。

Safari で使います。どちらか一方の方法でOKです。

方法A: ブックマークで使う(アプリ不要)

  2. Safari で今のページを開いたまま、共有ボタン →「ブックマークを追加」で保存します。
  3. ブックマーク一覧で今のブックマークを長押し →「編集」。名前を「talklogで保存」にし、アドレス欄を消して、コピーした文字列を貼り付けて保存します。

方法B: アプリ「Userscripts」で使う(ボタンが出て便利)

  1. App Store で無料アプリ「Userscripts」を入れ、Safari の機能拡張で有効にします。
  2. Safari でこのリンクを開き、機能拡張から「インストール」します: talklog.user.js
  3. zeta のトーク画面の右下に 「talklog」 ボタンが出るようになります。

Chrome で使います。

  2. 今のページをブックマークに追加し、ブックマークを編集。名前を「talklogで保存」に、URLをコピーした文字列に置き換えて保存します。
  3. 使うときは、zeta のトーク画面でアドレスバーに talklogで保存 と入力し、候補に出たブックマーク(★)をタップします。

Firefox(Android) に拡張機能「Violentmonkey」を入れて、talklog.user.js をインストールする方法もあります(トーク画面にボタンが出ます)。

短い版で動かないとき(全部入り版)

上のブックマークは、毎回このサイトから本体を読み込みます。zeta 側の設定で外部の読み込みが止められて動かない場合は、本体を丸ごと入れた長い版を試してください(更新は自動では入りません)。

貼り付けたあと、先頭の javascript: が消えていないか確かめてください。ブラウザが自動で取り除くことがあります。消えていたら手で打ち足してください。

2. 保存する

  1. ブラウザで zeta(Web版) を開き、保存したいトークの画面を表示します。
  2. ブックマーク「talklogで保存」(またはトーク画面の「talklog」ボタン)を押します。画面の下にパネルが出て、まず最新の発言まで自動で読み込みます。
  3. いちばん古い発言まで、ゆっくり上へスクロールします。パネルの 「自動で遡る」 を押すと自動で上まで戻ります。
  4. 「書き出す」 を押すと、talklog_ ではじまる HTML ファイルが保存されます。

保存できたら、必ずファイルを開いて確かめてください。いちばん古い発言と新しい発言が入っていれば成功です。足りないときは、もう一度上まで遡ってから書き出してください。

  • 集められるのは、画面に読み込まれた発言だけです。上まで遡らないと、遡ったところから先しか入りません。
  • 発言の日時、画像・ボイス・スタンプは入りません(文字だけです)。
  • 再生成した候補は、そのとき表示しているものだけが入ります。
  • zeta の画面の作りが変わると、動かなくなることがあります。

3. 書き出したログを見る

保存した talklog_….html を選ぶと、ここで読めます。検索・テキストでの保存・印刷(PDF)もできます。
