zetaのトークを、
吹き出しのまま手元に保存

zeta(Web版)のトーク画面で動かすと、読み込まれた発言を集めて、1つのHTMLファイルに書き出します。ファイルはブラウザで開くだけで読めます。無料で、登録もいりません。

読み取った内容はあなたの端末の中だけで扱い、どこにも送信しません。

zeta 非公式のツールです。使う前に、下の「利用上の注意」を読んでください。

黒羽 蓮読みかけの本に栞を挟んで、顔を上げる。
……遅い。待ちくたびれた。
放課後の図書室に、雨の音だけが響いている。
あなたごめん、委員会が長引いて。

利用上の注意

talklog は zeta で自分が見られるトークを読み取り、この端末に保存して整理するための非公式ツールです。使う前に、次の点に注意してください。

  • zeta 公式の機能ではありません。zeta の運営から、動作の保証や利用の許可は受けていません。
  • トークを集めるのに、画面のスクロールや、ページの中身（DOM）からの読み取りなど、zeta が公式に用意していない方法を使います。「自動で遡る」の間は、夢の「のぞく」も talklog が押して開きます。
  • 自動での読み取りや一括の保存が zeta の規約に反するかどうかは、運営の判断によります。とくに、次の項目にあたるおそれがあります。使う前に、最新の利用規約と運営規約を確かめてください。
    • 利用規約の禁止事項⑤「故意にサーバーに負担をかける行為」「自動で遡る」は古い発言を続けて読み込みます。
    • 利用規約の禁止事項⑩「本サービスにてユーザーに提供する情報を当社が本サービスの機能として提供する方法以外の方法で利用する行為」トークを zeta の外のファイルに書き出して読みます。
    • 利用規約の禁止事項⑫「当社による本サービスの運営を妨害するおそれのある行為（マクロ、ウイルスの拡散、DDoS攻撃等）」スクロールと「のぞく」を自動で操作します。
    • 運営規約（2）大量のアクセスがあると、ログインが一時的に制限されることがあります。
  • 動かす回数や使い方によっては、zeta に負担をかけたり、利用を制限されたりするおそれがあります。短い間に何度も取り直すのは避け、zeta の画面にエラーや制限の表示が出たら「止める」を押してやめてください。
  • 使ったことで起きたアカウントの制限、ログの抜けや重なり、そのほかの不利益について、作者は責任を負えません。
  • 保存したログには個人的な会話やほかの人の情報が入っていることがあります。ファイルの扱いに気をつけてください。

ログを共有するとき（zeta の規約より）

  • アンリミテッドモードで生成された扇情的・暴力的な内容を、SNS などで共有することは、運営規約（7）で禁止されています。
  • 他の人が作ったプロットの文や画像を含むログは、作者の権利を侵害しないよう気をつけて扱ってください（利用規約の禁止事項⑨・運営規約（9））。

talklog は自分が見られるトークを自分のために保存・整理するためのツールです。保存したログを転載・再配布したり、ほかの人に見せたりするときは、zeta の規約に従ってください。ご自身の判断と責任でお使いください。

talklog のパネルを初めて開いたときにも、この注意の要点を出します。「確認して使う」を押すまで、talklog は画面を動かしません。

1. 準備(はじめの1回だけ)

zeta の更新でトークの画面が別の枠(iframe)に移り、ブックマーク(ブックマークレット)では使えなくなりました。下の手順で、拡張機能にユーザースクリプトを入れて使ってください。前から talklog のユーザースクリプトを使っている人も、下のリンクから入れ直してください。

Chrome・Edge・Firefox・Safari で使えます。拡張機能「Tampermonkey」を使います。

  1. ブラウザに拡張機能「Tampermonkey」を入れます。
  2. Chrome と Edge では、拡張機能の管理画面で Tampermonkey の「詳細」を開き、「ユーザー スクリプトを許可する」をオンにします。この項目が無いブラウザでは、何もしなくて構いません。
  3. talklog.user.js を開いて「インストール」を押します。
  4. zeta のトーク画面の右下に 「talklog」 ボタンが出るようになります。

Safari で使います。無料アプリ「Userscripts」を使います。

  1. App Store で「Userscripts」を入れ、設定アプリにある Safari の「機能拡張」で、Userscripts をオンにします。
  2. 同じ画面で、Userscripts をすべての Web サイトで「許可」にします。zeta のページ(zeta-ai.io)とトークの枠(frame.pingpong.ai)の両方で動かす必要があるためです。
  3. Safari で talklog.user.js を開き、機能拡張のメニューから「インストール」します。
  4. zeta のトーク画面の右下に 「talklog」 ボタンが出るようになります。

Firefox で使います。Android の Chrome には拡張機能を入れられません。

  1. Firefox に拡張機能「Tampermonkey」か「Violentmonkey」を入れます。
  2. Firefox で talklog.user.js を開いて「インストール」を押します。
  3. zeta のトーク画面の右下に 「talklog」 ボタンが出るようになります。

talklog はトークの枠の中で発言を読み取り、zeta のページの側でファイルを保存します。拡張機能を使うサイトを選ぶときは、zeta-ai.io と frame.pingpong.ai の両方を許可してください。

2. 保存する

  1. ブラウザで zeta(Web版) を開き、保存したいトークの画面を表示します。
  2. トーク画面の右下の 「talklog」 ボタンを押します。画面の下にパネルが出て、まず最新の発言まで自動で読み込みます。
  3. いちばん古い発言まで、ゆっくり上へスクロールします。パネルの 「自動で遡る」 を押すと自動で上まで戻ります。
  4. 「書き出す」 を押すと、talklog_ ではじまる HTML ファイルが保存されます。

保存できたら、必ずファイルを開いて確かめてください。いちばん古い発言と新しい発言が入っていれば成功です。足りないときは、もう一度上まで遡ってから書き出してください。

  • 集められるのは、画面に読み込まれた発言だけです。上まで遡らないと、遡ったところから先しか入りません。
  • 入るのは文字だけで、発言の日時、画像・ボイス・スタンプは入りません。
  • 再生成した候補は、そのとき表示しているものだけが入ります。
  • 「のぞく」で見る夢の中身も入ります。「自動で遡る」の間は、最新の返答より前の夢を talklog が開いて読みます。開けるのは一度見た夢だけなので、ピースはかかりません。最新の返答の夢と、手でスクロールしている間に出てきた夢は、「のぞく」を押すと入ります。古い返答の夢で、まだ見ていない物は、もう見られないので入りません。
  • ファイルが保存されないときは、パネルに出る「共有で保存」か「HTMLをコピー」でも保存できます。
  • zeta の画面の作りが変わると、動かなくなることがあります。

3. 書き出したログを見る

保存した talklog_….html を選ぶと、ここで読めます。検索・テキストでの保存・印刷(PDF)もできます。

zeta のトーク画面に近い見た目で読みたいときや、立ち絵つきで自動再生したいときは Talklog Viewer(別のページ)も使えます。
